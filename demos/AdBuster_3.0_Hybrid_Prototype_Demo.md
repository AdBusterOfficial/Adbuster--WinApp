
# AdBuster 3.0 — Hybrid Prototype Demo

[![AdBuster 3.0 — Hybrid Prototype Demo](https://img.youtube.com/vi/jprODtEdIpo/0.jpg)](https://youtu.be/jprODtEdIpo?si=p3QyttgQVAapupnH)

This video presents the first demo of the AdBuster 3.0 hybrid prototype, integrating audio monitoring, ML-based ad-like signal detection, CEPA logic, volume-target management, and Broadlink IR control in a single application.

The prototype explores how these components work together to support context-aware TV volume stabilization. This initial demonstration documents the experimental integration and behaviour of the combined system.
