## 📼 CEPA Event Recorder
### Behavioral Telemetry & Analytics Engine

CEPA Event Recorder is a lightweight, non-blocking behavioral telemetry system designed for **AdBuster PRO** and **CEPA Logic**.

Instead of writing traditional debug logs, the recorder continuously captures observations, decisions, actions, and system behavior in a structured SQLite database without impacting real-time audio processing.

---

## ⚡ Key Features

✅ Non-blocking architecture

✅ Dedicated background writer thread

✅ SQLite database storage

✅ WAL mode for high-performance writes

✅ Event batching

✅ Repeated event coalescing

✅ Session tracking

✅ Real-time safe operation

✅ Long-term behavioral analytics

---

## 🏗 Architecture

```text
┌─────────────────┐
│ Audio Callback  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Event Queue     │
│ (Memory Buffer) │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Writer Thread   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ SQLite Database │
└─────────────────┘
```

Audio processing never waits for disk operations.

All database writes are performed on a dedicated background thread to guarantee smooth and uninterrupted audio processing.

## 🎯 What Gets Recorded

### 🎧 Audio Observations

```json
{
  "rms": 0.34,
  "std": 0.11,
  "delta": 0.06,
  "context": "content"
}
```

Recorded at a low, controlled frequency to avoid generating excessive data while still preserving system behavior.

---

### 📢 Advertisement Detection Events

```json
{
  "event_type": "advertisement_detected",
  "probability": 0.94
}
```

Captures advertisement detection decisions generated by CEPA or machine learning models.

---

### 🔉 Volume Reduction Actions

```json
{
  "event_type": "volume_reduction",
  "from": 28,
  "to": 14
}
```

Stores every automatic volume reduction performed by AdBuster PRO.

---

### 🔊 Volume Recovery Actions

```json
{
  "event_type": "volume_restore",
  "from": 14,
  "to": 28
}
```

Records every volume restoration event initiated by CEPA.

---

### 🧠 Behavioral State Changes

```json
{
  "event_type": "context_change",
  "old_state": "advertisement",
  "new_state": "content"
}
```

Allows reconstruction of the complete decision timeline.

---

## 🚀 Smart Event Coalescing

Repeated events are automatically grouped together.

Instead of storing:

```text
command_queued
command_queued
command_queued
command_queued
command_queued
```

the recorder creates:

```json
{
  "aggregated": true,
  "repeat_count": 87
}
```

This dramatically reduces database growth during long-running sessions.

## 🗄 Database Structure

Database location:

```text
pro_data/cepa_behavior.sqlite3
```

Main table:

```sql
observations
```

Columns:

```text
id
ts_utc
session_id
event_type
context
source
command
payload_json
```

Every observation is timestamped and associated with the active CEPA session.

## 🔬 How AdBuster PRO Uses It

The recorder functions as a behavioral black box for AdBuster PRO.

It continuously records:

• Audio observations

• Advertisement detections

• CEPA decisions

• Volume changes

• Command execution results

• Context transitions

• Recovery actions

This allows developers to understand exactly why the system behaved in a particular way.

Example flow:

```text
Advertisement detected
         ↓
Volume reduced
         ↓
Advertisement ends
         ↓
Content stabilizes
         ↓
Volume restored
```

Every step can be reviewed and analyzed later.
