# ML/Auto Mode — AdBuster PRO

This diagram illustrates how CEPA PRO behaves when ML/Auto Mode is enabled.
ML/Auto Mode allows the system to automatically switch between CEPA modes based on real‑time audio classification, ensuring optimal behaviour without manual intervention.

## 🤖 What ML/Auto Mode Represents

ML/Auto Mode is an automated decision layer that evaluates:
- MFCC‑based audio features,
- CEPA context predictions,
- confidence thresholds,
- recent behaviour history.

When enabled, CEPA PRO dynamically selects the most appropriate mode (MUSIC, DIALOG, NORMAL, ADS, AD MODE, FALLBACK) based on the current audio environment.

## ⚙️ ML/Auto Mode Behaviour

With ML/Auto Mode turned on, CEPA:
- auto‑switches modes based on ML predictions,
- stabilizes transitions between contexts,
- prevents incorrect mode locking,
- maintains safe volume behaviour,
- reduces manual configuration needs.

This ensures CEPA always reacts with the correct logic for the detected audio type.

## 🔍 Why ML/Auto Matters

ML/Auto Mode is essential for:
- seamless real‑time behaviour,
- reducing user interaction,
- improving detection accuracy,
- stabilizing CEPA output across diverse audio conditions,
- ensuring the system adapts instantly to changes.

It is the core automation layer of CEPA PRO.
